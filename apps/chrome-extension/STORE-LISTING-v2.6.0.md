## Detailed description

**Stop re-explaining your context to every AI.**

memory.wiki Clipper turns anything you find on the web into a clean,
sharable URL. Paste that URL into Claude, ChatGPT, Cursor, Codex — every
AI fetches the same markdown, every time.

### What it captures

- **Whole pages** — articles, docs, GitHub READMEs, recipes, papers.
  One click → a memory.wiki URL with the article's metadata (author,
  date, source), no nav cruft, no ads, no fake mockups.
- **AI conversations** — hover any message on chatgpt.com, claude.ai,
  or gemini.google.com to save just that Q+A pair, or hit the popup
  to save the whole thread.
- **Social posts (NEW in 2.6)** — per-post save buttons on X /
  Twitter / Threads. Captures author, timestamp, body, attached
  images, and a link back to the original.
- **Images (NEW in 2.6)** — hover any image on the web → save to
  your reusable image library at memory.wiki. Insert into any future
  doc with one click.
- **Selections** — highlight text → ⌘⇧X / Ctrl+Shift+X → only the
  selection becomes the doc.

### AI does the work (NEW in 2.6)

Type a short intent in the popup — "summarize in 5 bullets", "extract
code blocks only", "translate to Korean", "Cursor-ready reference" —
and the page gets rewritten by Claude / GPT before saving. Recipe,
movie, paper, and product pages get a templated extraction
automatically; no intent needed.

### Why URLs, not files

Your memory.wiki URL is the same payload everywhere. ChatGPT reads it
as markdown. Claude reads it as markdown. Cursor reads it as markdown.
You stop pasting your context 5 times. Sign in once, see the same
captures on web, VS Code, desktop, iOS, Android, MCP, CLI.

### Privacy

- Captures are tied to YOUR account. Private by default.
- The extension only fetches pages YOU click on.
- No tracking, no analytics, no telemetry.

### Keyboard shortcuts

- ⌘⇧E / Ctrl+Shift+E — capture current page
- ⌘⇧X / Ctrl+Shift+X — capture selection
- Configure at chrome://extensions/shortcuts
