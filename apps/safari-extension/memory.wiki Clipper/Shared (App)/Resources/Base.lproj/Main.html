memory.wiki Clipper

Capture any page into a memory.wiki URL that ChatGPT, Claude, Gemini, Cursor, and any AI can read.

Enable in Safari

  1. 1Open Safari on this device.
  2. 2Tap the puzzle icon in the URL bar, then Manage Extensions and toggle memory.wiki Clipper on.
  3. 3Tap All Websites › Allow so capture works everywhere.

Can’t find it? Open Settings › Apps › Safari › Extensions instead.

Enable in Safari

  1. 1In Safari, open Settings from the Safari menu (Command + ,).
  2. 2Select the Extensions tab.
  3. 3Tick memory.wiki Clipper to enable it, then allow it on All Websites.
